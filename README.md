# TripSolApp

## Overview

TripSolApp is a travel planning and recommendation application developed as part of the IIT Indore Summer of Code (IITISoC) program. The project focuses on helping users discover travel destinations and receive personalised travel suggestions based on their preferences.

## Features

* Travel destination recommendations
* User preference-based suggestions
* Frontend and backend integration
* Dynamic recommendation system
* Collaborative full-stack development

## Tech Stack

### Frontend

* Flutter / Dart

### Backend

* JavaScript
* API integration
* Database connectivity

## Project Structure

```text
Frontend/   -> User interface and client-side application
backend/    -> Server-side logic and recommendation modules
```
